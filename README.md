# Noclip Accuracy

**ES** — Noclip para Geometry Dash (Geode) con porcentaje de precisión (accuracy). La precisión es el % de ticks de física sin colisión.. También cuenta golpes y permite una precisión mínima (si bajas de ella, mueres de verdad).
**EN** — Noclip for Geometry Dash (Geode) with an accuracy percentage (% of physics ticks without a collision), hit counter and optional minimum accuracy.

- Geometry Dash **2.2081** · Geode SDK **5.10.1**
- Desactivado por defecto: actívalo en los ajustes o con el atajo de teclado.

## Aviso / Notice
Un noclip es trampa: no lo uses para récords, listas ni pasadas oficiales; tu cuenta podría ser sancionada.

## Compilar / Build
Sube el proyecto a GitHub y ejecuta *Actions → Build NoclipAccuracy (Windows)*.
